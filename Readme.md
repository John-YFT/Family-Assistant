# Tailwind CSS
Tailwind CSS — это утилитарный CSS-фреймворк, который позволяет быстро создавать пользовательские дизайны. Он предоставляет классы, которые можно комбинировать, чтобы применять стили к элементам, что упрощает процесс разработки. Вместо того чтобы писать длинные списки свойств CSS, вы можете использовать короткие классы, чтобы наделить несколько объектов одинаковыми стилями.

## Пример использования
Вот пример компонента React с использованием стилей Tailwind CSS:

```javascript
import React from 'react';

const Button = () => {
  return (
    <button className="bg-blue-500 text-white font-bold py-2 px-4 rounded">
      Нажми меня
    </button>
  );
};

export default Button;
```

В этом примере кнопка имеет синий фон, белый текст, жирный шрифт, отступы и закругленные углы, все это задается с помощью классов Tailwind CSS.
